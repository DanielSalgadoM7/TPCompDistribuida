# SLIC Distribuído

Projeto acadêmico da disciplina de Computação Distribuída. A implementação, os
comandos de instalação e execução e a documentação técnica completa estão em
[slic-dist/README.md](slic-dist/README.md).

O projeto implementa segmentação SLIC com cliente gRPC, líder e workers, eleição
Bully, heartbeat e relógios lógicos de Lamport. A auditoria das decisões, correções
e limitações está em [docs/RELATORIO_TECNICO.md](docs/RELATORIO_TECNICO.md).
